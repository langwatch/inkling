# The process

Inkling starts from the floor and climbs.

The floor is what a model writes by default: grammatical, average, AI slop. The rules and lints in this process are a ratchet: as the piece climbs, they keep it from sliding back down. The ceiling comes from contest, in [directions](5-directions.md) and [reader tests](8-reader-test.md), where versions compete and readers pick.

Breaking the model's own default habits is the main point. Breaking one of the rules here needs a strong reason, written as a [waiver](../tools/waivers.md) a fresh judge accepts.
