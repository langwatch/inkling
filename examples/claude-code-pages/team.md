## What colleagues ask it

Once it's in the channel, the questions change. Sales asks which trials went quiet this week and gets drafts for the follow-ups. Support pastes an error from a customer and gets the cause, with a link to the line of code.

Your product lead asks what shipped since the last release and gets notes written for customers. Because the agent works with your repos, scripts and data tools, the answers are as good as the ones you'd get running it yourself.

## The usual ways to share it

Teams usually try one of these first. Here's what each asks of your colleagues, and what it asks of you.

- **Share your setup**: Send your skills, your MCP servers and a guide.
  - Each colleague needs Claude Code and a seat
  - The setup drifts within a week
- **A seat for everyone**: Buy each colleague a Claude plan.
  - They get a chat, not your agent
  - None of your tools or your code
- **Your agent in a team chat**: Colleagues message your Claude Code the way they message you.
  - No Claude seat for them
  - Your skills and tools, kept by you

## Who runs it and where your code lives

ACME is made by ACME B.V., a company in the Netherlands, and runs in the European Union. Agents that run in ACME work on their owner's own computer, a separate machine with no path to ACME's database.

What your team writes in ACME is stored encrypted with a key for your workspace, and ACME never trains AI models on it. The security page explains the details, and the docs cover connecting Claude Code step by step.

## Set it up this afternoon

The first answer comes back in the channel, where everyone can see it.

1. **Make a workspace**: Create a free ACME workspace and invite one colleague.
2. **Connect Claude Code**: Paste the prompt ACME gives you into Claude Code.
3. **Add it to a channel**: Pick where it listens, such as #sales.
4. **Let them ask**: Your colleague mentions it, and the answer lands in the thread.

## Questions

- **Do my colleagues need to learn Claude Code?** No. They write in a channel, and your agent picks the skills and tools, as it does for you.
- **Whose Claude login does it use?** Yours, so their requests run on your Claude plan. An agent the whole team owns runs on a pool of Claude logins you add.
- **Can we keep using Slack?** Yes. Each person can link their Slack, and channels sync both ways, so no one has to move.
- **Can a colleague bring their own agent?** Yes. They connect it the same way, and agents work side by side in channels.
- **Does it work with Codex?** Yes. Codex connects with the same prompt and joins the channels you pick.
